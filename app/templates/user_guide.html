User Guide

Everything you need to use the Document Server — step by step.

What is this system?

The Related Document Server keeps all your scanned student documents — Certificates and POEs (Grade Books) — in one place. When you add a document, the system reads it automatically and pulls out the important details (student name, course, ID number, date). You can then search for any document in seconds, and quickly check anything the system wasn't sure about.

You don't need any technical knowledge. This guide walks you through each task with pictures. Use the quick links below to jump to what you need.

🧭 Finding your way around

Along the top of every page is the menu. These are the only places you'll ever need:

  • Dashboard

    The home page. See recent documents, how many need review, and add new documents.

  • Search

    Find any document by student, course, ID number, or date.

  • Review Queue

    The list of documents the system wasn't fully sure about, waiting for you to check.

  • Settings

    For administrators — set up document types and the reader. You can usually ignore this.

📤 Upload one document

The quickest way to add a single Certificate or POE:

  1. Go to the Dashboard

    Click Dashboard in the top menu.

  2. Scroll down to “Upload Document”
  3. Choose the document type

    Pick POE (Grade Books) or Certificates from the drop-down.

  4. Add your file

    Drag the file onto the box, or click the box to browse your computer. PDF, PNG, JPG and TIFF files all work.

  5. Wait a moment

    The system reads the document and opens its details automatically. That's it — it's saved.

💡

After uploading, you'll land on the document's details page. If everything looks right, you're done. If a box is empty or wrong, just type the correct value and click Save Changes.

🗂️ Upload many at once (Bulk Upload)

Have a whole stack to add? Bulk Upload handles them all — one at a time so nothing gets missed.

  1. Go to the Dashboard

    Scroll down to the Bulk Upload section (below the single upload).

  2. Select all your files

    Drag several files onto the box, or click it and hold Ctrl (or Shift) to pick many. Certificates and POEs can be mixed together — the system works out the type for you.

  3. Watch the progress

    Each file moves through the steps: Uploading → Identify → OCR Reading → AI Reading → Done. They process one after another.

  4. Check the results

    Each file ends with a green Approved or an orange Needs Review label. Click a label to open that document.

💡

Leave the page open until every file shows a result. Anything marked Needs Review will also appear in the Review Queue for you to fix later.

📝 Check & fix documents (Review Queue)

Sometimes the system can't read a field clearly — for example, handwriting or a missing ID number. Those documents wait in the Review Queue so you can quickly put them right. Nothing is lost; they're just held for a human to confirm.

  1. Open the Review Queue

    Click Review Queue in the top menu. Each row shows what's missing in the Reason column.

  2. Open a document

    Click the Review button on the right of the row.

  3. Compare with the scan

    The original scan is shown on the left. Read the details from it and fill in or correct the boxes on the right. Fields marked with a * are required.

  4. Save

    Click Save Changes. Once all required fields are filled, the document leaves the queue automatically and is filed away.

⚠️

The Delete Document button removes a document permanently and can't be undone. Only use it if a file was uploaded by mistake.

🔍 Find a document

The Search page finds any document already in the system.

  1. Click Search in the top menu
  2. Type what you're looking for

    Use the big search box for anything — a name, a course, or an ID number. Or use the boxes below to search a specific field or a date range.

  3. Open a result

    Click View on any row to open that document.

🏷️ What the labels mean

You'll see these small coloured labels next to documents. Here's what each one means:

Complete Complete / Approved — all required details were found. Nothing for you to do.
Needs Review Needs Review — a detail is missing or unclear. Open it, check it, and Save.
⚠ AI error AI error — the automatic reader had a problem (for example, it couldn't connect). The document is safe — just fill the details in by hand. If this keeps happening, tell your administrator.

On a document's details page you may also see “Extraction: Rules only” or “Rules + AI”. This simply tells you whether the system needed its smart AI reader for that document. It doesn't change anything you need to do.

⚙️ Settings (for administrators)

Most people never need this page. Administrators use Settings to:

  • Manage document types

    Add or change the types (like POE and Certificate) and the fields each one collects.

  • Set up the automatic reader (AI)

    Enter the reader's connection details and press Test Connection to confirm it's working.

⚠️

Changing settings affects everyone. If you're not sure, leave this page alone and ask your administrator.

↑ Back to top

💬 Need help?

If something doesn't look right, don't worry — nothing you do here can lose a document. The safest steps are always: open the document, compare it with the scan on the left, correct the boxes, and click Save Changes.

If a document keeps showing an AI error, or a page won't load, contact your system administrator.
